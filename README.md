# Portfolio Personal — Jan García

Portfolio web personal desarrollado para presentar mi perfil profesional, proyectos técnicos y trayectoria en el ámbito de los sistemas, redes y ciberseguridad.

Demo online:  
https://jangarcia93.github.io/

---

## Descripción

Este portfolio tiene como objetivo mostrar de forma clara y visual:

- Mi perfil profesional como técnico en sistemas (ASIR)
- Proyectos prácticos orientados a ciberseguridad y administración de sistemas
- Experiencia laboral y formación académica
- Objetivos profesionales y plan de desarrollo

El sitio está diseñado con un enfoque moderno, responsive y orientado a destacar proyectos técnicos reales.

---

## Tecnologías utilizadas

- HTML5
- CSS3 (Glassmorphism + diseño responsive)
- JavaScript (vanilla)
- GitHub Pages (hosting)

---

## Funcionalidades principales

- Sistema multi-idioma (ES / CA / EN / DE)
- Diseño moderno con efecto glassmorphism
- Responsive (adaptado a móvil y escritorio)
- Secciones estructuradas:
  - Sobre mí
  - Proyectos
  - Currículum
  - Proyección profesional
  - Plan de promoción personal (IPOP)
  - Contacto
- Animaciones suaves (scroll reveal)
- Visualización de tecnologías por proyecto mediante iconos
- Enlaces directos a repositorios de GitHub
